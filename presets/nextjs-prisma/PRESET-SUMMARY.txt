SETUP INSTRUCTIONS FOR END USERS:
================================================================================

1. Copy preset to project:
   cp -r presets/nextjs-prisma ~/my-new-app

2. Install dependencies:
   npm install

3. Configure environment:
   cp .env.example .env.local
   # Edit .env.local with your Neon PostgreSQL connection string

4. Initialize database:
   npm run db:push

5. Start development:
   npm run dev

6. Write your feature spec:
   - Use SPEC-TEMPLATE.md as guide
   - Create SPEC.md in product manager language
   - Share with your AI agent
